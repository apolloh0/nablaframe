# Nablaframe

A small GPT trained from scratch, built so its training run and forward pass can be replayed, inspected and manipulated. Every explanation it shows carries a measured faithfulness number.

## Read first

- `docs/charter.md`: goal, principles, scope. Changes need a C-entry.
- `docs/decisions.md`: every ruling so far. Check it before assuming a choice is open.
- `docs/specs/`: the current phase spec is the one you implement against.

## How work arrives

Specs, contracts, stubs and tests are written in a Claude Project and committed here. Implement against them. If a spec is ambiguous or contradicts the code or a decision, stop and report the conflict instead of choosing.

## Hard rules

- Never change oracle policy or a pinned tolerance (`src/nablaframe/oracle/`) without a D-entry in `docs/decisions.md` and a discrimination test. Report the need; do not make the change.
- Deltas add new files. Never replace an existing file wholesale; apply changes to existing files only as the explicit edits you were given.
- Files under `reports/` are generated by gate scripts. Never hand-edit them, and never state a gate result that is not in a report.
- The trace store is append-only. Corrections are new events that supersede old ones.
- Do not start work from a later phase before the current human gate is ruled in `docs/decisions.md`.

## Conventions

- Python 3.12, uv. Three environments: `nf-jax` (reference), `nf-metal` (accelerator probe), `nf-torch` (cross-checks and fallback). See the current spec for contents. Every lane command names its extra, for example `UV_PROJECT_ENVIRONMENT=.venv-jax uv run --extra jax ...`; without it, uv resyncs the lane to the base packages.
- Records are frozen dataclasses with a JSON form.
- Tap names follow TransformerLens hook names exactly. Tensors carry named axes.
- Tests live in `tests/`. Run them in the jax lane: `UV_PROJECT_ENVIRONMENT=.venv-jax uv run --extra jax pytest`. Plain `uv run pytest` skips the JAX tests, so work isn't done until the jax-lane run has zero skips.
